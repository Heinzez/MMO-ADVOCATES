# Security and privacy notes

- Use HTTPS wherever credentials or client information are handled.
- Hash passwords with a purpose-built password hashing function; never store plaintext passwords.
- Enforce least privilege and case-assignment checks in backend policies for every request.
- Keep case data out of public pages, search indexing, and public caches.
- Use secure session and password-reset flows; do not log passwords, reset tokens, or confidential case details.
- Audit case, follow-up, and published-content changes with actor and timestamp.
- Keep backups access-controlled, define retention, and verify recovery.
- Design and operate the system in line with the Kenya Data Protection Act and the firm's approved privacy practices.
